# DataPilotFlow Domain

Core domain models and schemas for DataPilotFlow.

Contains all data models used across the system:
- Agent configurations
- Conversation & message models
- Knowledge base models
- Embedding & generative models
- User & role models
- Notification models
- Vector DB collection models
- Event definitions
- Prompt templates
- Core exceptions

## Installation

```bash
pip install datapilotflow-domain
```

## Usage

```python
from datapilotflow.domain import Agent, Document, User
```
