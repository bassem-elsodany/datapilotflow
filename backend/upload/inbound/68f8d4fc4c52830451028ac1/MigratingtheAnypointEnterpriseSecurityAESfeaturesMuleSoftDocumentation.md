# Migrating the Anypoint Enterprise Security (AES) features

In Mule 4, the Anypoint Enterprise Security module was split into different
modules:

  * [Cryptography Module](cryptography) replaces the Mule 3 Encryption and Signature modules

  * [Secure Configuration Properties Module](secure-configuration-properties) replaces the Mule 3 Secure Property Placeholder

  * [Validation Module](../../validation-connector/latest/) incorporated functionality from the Mule 3 Filters Module

  * [OAuth2 Provider](../../oauth2-provider-module/latest/oauth2-provider-module-reference) replaces the Mule 3 OAuth2 Provider

Please refer to the above modules documentation for information on how to
migrate to Mule 4.
