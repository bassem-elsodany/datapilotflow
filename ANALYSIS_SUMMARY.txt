KEY FINDINGS
================================================================================

ARCHITECTURE:
- Two main wizard flows built with reusable ColorfulVerticalStepper component
- Left sidebar (200px) for step tracking, right area (flex) for content
- Mantine UI framework with custom CSS animations

KNOWLEDGE SOURCE WIZARD (5 Steps):
  Step 0: Basic Info & Scraping (REQUIRED)
    - Configuration name, description, scraping mode, URL/file, crawl depth
    - Dynamic field visibility based on scraping mode selection
  
  Step 1: Domain Filtering (OPTIONAL)
    - Allowed/blocked subdomains, URL patterns with wildcards
    - Add/remove controls for dynamic fields
  
  Step 2: Content Filter (OPTIONAL)
    - CSS selectors for target elements
    - Floating test panel for real-time preview
  
  Step 3: Generation (OPTIONAL)
    - Output format (HTML/Markdown), generation method
    - LLM content filter creation via modal
    - Cost notices for LLM processing
  
  Step 4: Review & Confirmation (REVIEW)
    - Read-only summary of all settings

KNOWLEDGE JOB WIZARD (6 Steps):
  Step 0: Job Setup (REQUIRED)
    - Config selection, job name, description
  
  Step 1: Vector DB Collection (REQUIRED)
    - Toggle between creating new or using existing collection
    - Inheritance display for existing collections
  
  Step 2: Document Splitter (REQUIRED, context-dependent)
    - Choice between text-based (chunk size/overlap) or document-based splitting
    - Intelligent recommendations based on source configuration
    - Auto-calculation of chunk overlap (12.5% of chunk size)
  
  Step 3: Embedding Model (CONDITIONAL)
    - Skipped if using existing collection
    - Provider, model, and vector dimension selection
    - Active provider status validation
  
  Step 4: Processing Settings (REQUIRED)
    - Batch size, file output options, collection management flags
  
  Step 5: Review & Create (REVIEW)
    - Complete configuration summary
    - Configuration alignment indicators

VALIDATION STRATEGY:
- Step-by-step validation before progression
- API validation for uniqueness checks (collection names)
- Explicit submit flag prevents accidental submission on final step
- Context-dependent validation (some fields required based on choices)

COLORFUL VERTICAL STEPPER FEATURES:
- Circular step indicators with color gradients
- Step number badges, checkmarks for completed steps
- Pulsing animation for active step with rotating ring
- Connecting lines between steps with gradient colors
- Fade-in animation for content card
- Hover effects with glassmorphism on non-active steps
- Mobile-responsive with reduced animations

UX PATTERNS IDENTIFIED:
1. Conditional Field Visibility - Dynamic forms based on selections
2. Modal Sub-wizards - LLM filter creation without leaving wizard
3. Floating Test/Preview Panels - Real-time content testing
4. Auto-calculation & Smart Defaults - Dependent field calculations
5. Intelligent Recommendations - Context-based suggestions
6. Progressive Disclosure - Advanced options hidden until needed
7. Multi-step API Validation - Pre-flight checks before progression
8. Step-based Review & Confirmation - Final summary before submission
9. Breadcrumb Navigation - Context and quick navigation
10. Edit Mode State Preservation - Loading existing data into forms

COLOR SCHEME:
- Teal (#45c9bb) - Initial/input stages
- Green (#bbe773, #3bc57d) - Processing/filtering stages
- Yellow (#ddde65) - Content/selection stages
- Purple (#ae89ae) - Final/review stages

ANIMATION TIMINGS:
- Content card transition: 300ms fade
- Step indicator scale: 300ms
- Connecting line growth: 600ms
- Content card slide-in: 400ms
- Active step pulse: 2s infinite
- Step hover translation: instant with 6px offset

RECOMMENDATIONS FOR PIPELINE BUILDER UX
================================================================================

1. ADOPT THE COLORFUL VERTICAL STEPPER
   - Use for multi-stage pipeline construction
   - Each pipeline segment/node as a step
   - Consistent visual language

2. NODE CONFIGURATION MODAL PATTERN
   - Modal dialogs for node settings (not full pages)
   - Quick edit controls with advanced options via buttons
   - Async save without wizard progression

3. VALIDATION & REAL-TIME FEEDBACK
   - Show connection validity immediately
   - Color-code nodes based on state (invalid/valid/active)
   - Prevent invalid pipeline execution

4. VISUAL STATE INDICATORS
   - Use same color scheme for consistency
   - Pulsing animations for active nodes
   - Checkmarks for completed configurations

5. FLOATING PREVIEW/TEST PANEL
   - Like content filter wizard
   - Show sample data through pipeline
   - Real-time validation output

6. CONFIGURATION INHERITANCE
   - Child nodes inherit parent settings
   - Show inherited values as disabled
   - Allow override with visual indicators

7. SAVE & EXECUTE FLOW
   - Save for configuration changes
   - Separate "Run Pipeline" button
   - Full review before execution

================================================================================
IMPLEMENTATION INSIGHTS
================================================================================

Component Reusability:
- ColorfulVerticalStepper is fully generic and reusable
- Props: activeStep, completedSteps, steps[], children, onStepClick
- Step configuration: label, description, icon, color, gradient

State Management:
- Mantine useForm for field management
- useState for activeStep, completedSteps
- Explicit submit flag prevents accidental submissions
- Validation on step progression

Performance:
- Lazy load heavy components (modals, floating panels)
- Debounce API validation checks
- Conditional rendering for optional steps
- React.memo for non-dependent content

Accessibility:
- Semantic HTML with ARIA labels
- Keyboard navigation support
- Focus management on transitions
- Screen reader support for progress

Error Handling:
- User-friendly validation messages
- Specific error highlighting
- Recovery options (edit previous steps)
- Retry mechanisms for API failures
