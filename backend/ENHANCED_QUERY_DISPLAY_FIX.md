# Enhanced Query Display Fix

## Problem

User reported: **"I STILL ONLY SEE ORIGINAL QUERY. I NEED TO SEE THE ENHANCED VERSION AS WELL BELOW THE ORIGINAL ONCE IT'S GENERATED BY THE STRATEGY"**

When using a query enhancement strategy (HyDE, Multi-Query, Step-Back, Augmented, etc.) in the RAG Pipeline Processing Modal, the enhanced query was not being displayed even though the code to display it was already implemented.

## Root Cause

The backend was sending `enhanced_query` as a **dictionary object** from the workflow state, but the frontend was expecting a **simple string**.

### Backend Workflow State Structure

```python
# From src/workflow/state.py
class WorkflowState(TypedDict):
    enhanced_query: Optional[Dict[str, Any]]  # ❌ Dictionary, not string!
```

### Enhanced Query Dictionary Format

Different strategies store the enhanced query in different keys:

```python
# Step-Back Strategy
enhanced_query = {"step_back_query": "What are the fundamental concepts..."}

# HyDE Strategy
enhanced_query = {"hypothetical_answer": "In MuleSoft, HTTP listener..."}

# Multi-Query Strategy
enhanced_query = {"multi_query_variants": ["Query 1", "Query 2", "Query 3"]}

# Augmented Strategy
enhanced_query = {"augmented_queries": ["Original", "Variant 1", "Variant 2"]}

# Decomposition Strategy
enhanced_query = {"sub_queries": ["Sub 1", "Sub 2", "Sub 3"]}

# RAG Fusion Strategy
enhanced_query = {"fusion_perspectives": ["Perspective 1", "Perspective 2"]}
```

### Frontend Expected Format

```typescript
// Frontend expects a simple string
metadata: {
  originalQuery: string;
  enhancedQuery: string;  // ❌ Expected string, got dictionary!
  strategy: string;
}
```

## Solution

Added a helper function `extract_enhanced_query_text()` in the WebSocket router to extract the actual enhanced query text from the dictionary before sending it to the frontend.

### Implementation

#### 1. Helper Function

```python
# src/api/routers/agent/agent_websocket_router.py

def extract_enhanced_query_text(enhanced_query_dict: dict, strategy: str = None) -> str:
    """
    Extract the actual enhanced query text from the enhanced_query dictionary.

    Args:
        enhanced_query_dict: Dictionary containing enhanced query data
        strategy: The enhancement strategy used

    Returns:
        The enhanced query as a string
    """
    if not enhanced_query_dict:
        return None

    logger.debug(f"📝 Extracting enhanced query text from dict keys: {list(enhanced_query_dict.keys())}, strategy: {strategy}")

    # Extract based on known keys
    if "step_back_query" in enhanced_query_dict:
        result = enhanced_query_dict["step_back_query"]
        logger.debug(f"✅ Extracted step_back_query: {result[:100]}...")
        return result
    elif "hypothetical_answer" in enhanced_query_dict:
        result = enhanced_query_dict["hypothetical_answer"]
        logger.debug(f"✅ Extracted hypothetical_answer: {result[:100]}...")
        return result
    elif "multi_query_variants" in enhanced_query_dict:
        variants = enhanced_query_dict["multi_query_variants"]
        result = variants[0] if variants and len(variants) > 0 else None
        logger.debug(f"✅ Extracted multi_query_variants[0]: {result[:100]}...")
        return result
    elif "augmented_queries" in enhanced_query_dict:
        augmented = enhanced_query_dict["augmented_queries"]
        # Return first variant after original (index 1), or first if only one
        result = augmented[1] if augmented and len(augmented) > 1 else (augmented[0] if augmented else None)
        logger.debug(f"✅ Extracted augmented_queries[1]: {result[:100]}...")
        return result
    elif "sub_queries" in enhanced_query_dict:
        sub_queries = enhanced_query_dict["sub_queries"]
        result = sub_queries[0] if sub_queries and len(sub_queries) > 0 else None
        logger.debug(f"✅ Extracted sub_queries[0]: {result[:100]}...")
        return result
    elif "fusion_perspectives" in enhanced_query_dict:
        perspectives = enhanced_query_dict["fusion_perspectives"]
        result = perspectives[0] if perspectives and len(perspectives) > 0 else None
        logger.debug(f"✅ Extracted fusion_perspectives[0]: {result[:100]}...")
        return result

    logger.warning(f"⚠️ Could not extract enhanced query from dict: {enhanced_query_dict}")
    return None
```

#### 2. Updated WebSocket Message Handlers

**Location 1: Query Enhancement Stage**
```python
# Line ~502-507
# Include enhanced query if available
if chunk.get("enhanced_query"):
    enhanced_query_text = extract_enhanced_query_text(
        chunk["enhanced_query"], selected_strategy
    )
    if enhanced_query_text:
        stage_data["enhanced_query"] = enhanced_query_text  # ✅ Now a string!
```

**Location 2: Workflow Progress Tracking**
```python
# Line ~529-534
# Handle progress chunks
if chunk_type == "workflow_progress":
    # Update tracked variables
    if chunk.get("enhanced_query"):
        enhanced_query_text = extract_enhanced_query_text(
            chunk["enhanced_query"], selected_strategy
        )
        if enhanced_query_text:
            enhanced_query = enhanced_query_text  # ✅ Now a string!
```

**Location 3: Workflow Completion**
```python
# Line ~592-599
# Handle completion
elif chunk_type == "workflow_complete":
    final_response = chunk.get("response", "")
    documents = chunk.get("documents", [])
    # Extract enhanced query text from dictionary
    enhanced_query_dict = chunk.get("enhanced_query")
    if enhanced_query_dict and isinstance(enhanced_query_dict, dict):
        enhanced_query = extract_enhanced_query_text(
            enhanced_query_dict, selected_strategy
        )
    else:
        enhanced_query = enhanced_query_dict  # Already a string or None
```
