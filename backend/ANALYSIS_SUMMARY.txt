VALIDATION RULES
================

18 connection rules defined in pipelineRules.ts

REQUIRED PIPELINE STRUCTURE:
1. At least 1 data source
2. 1 document splitter
3. 1 embedding generator
4. 1 vector database

TYPICAL FLOW:
Data Source → Document Splitter → AI Tools → Vector Database → Output

AUTO-CONNECTION:
- New nodes automatically connect to compatible existing nodes
- Bidirectional connection checking
- Prevents orphaned nodes (in most cases)

---

CONFIGURATION FORMS
===================

STRUCTURE: Multi-step stepper (3-4 steps depending on node type)

DATA SOURCE NODES (4 steps):
1. Basic Info: name, description
2. Scraping: URL, crawl depth, content filter
3. Domain Filtering: whitelist/blacklist subdomains
4. Review: Summary

TEXT SPLITTER (3 steps):
1. Basic Info: name, description
2. Config: chunk size, overlap, batch size
3. Review: Summary

FORM VALIDATION:
- Required field validation
- Numeric range validation (crawl depth 1-10, threshold 0-1)
- Conditional validation (URL required except multiple_pages)
- Dynamic field display based on node type

DATA STRUCTURE (READY TO SEND)
==============================

PIPELINE OBJECT FORMAT:
{
  nodes: [
    {
      id: "uuid-string",
      type: "pipelineNode",
      position: { x: number, y: number },
      data: {
        id: "uuid-string",
        name: "User-friendly name",
        type: "website|textSplitter|etc",
        status: "pending|running|completed|failed",
        description: "string",
        configured: boolean,
        // Node-specific config follows
        scraping_mode?: string,
        url?: string,
        crawl_depth?: number,
        chunk_size?: number,
        chunk_overlap?: number,
        batch_size?: number,
        allowed_subdomains?: string[],
        blocked_subdomains?: string[],
        // ... etc
      }
    }
  ],
  edges: [
    {
      id: "edge-source-target",
      source: "node-id",
      target: "node-id",
      type: "arrow",
      animated: boolean,
      style: { stroke: string, strokeWidth: number }
    }
  ]
}

- ~3-4 nodes
- ~2-3 edges
